# 动态化模式（静态分镜 → 双平台视频提示词）

> 触发语：用户要"让分镜动起来 / 每格出视频提示词 / 变成拍摄脚本 / 动态故事板"。
> 前提：这条板已经走完静态流程——每格通过质检门、成品帧在手。**质检不过的格不许动态化**，先把静态格修好。
> 本模式不替代生视频工具；产出的是**可直接投喂 Seedance 2.0 或 MiniMax H3 的视频提示词**，每格成品帧作为首帧参考图传入。

## 一、核心映射：镜头单字段 → 视频提示词字段

静态镜头单里写的每一样东西，在视频提示词里都有明确去处，**不新增语义，只换语法壳**：

| 镜头单字段 | 去处 | 规则 |
|---|---|---|
| `anchors.characters` | 定妆块 / `subject_definitions` | 逐字复用，一字不改 |
| `anchors.scene` + `blueprint` | 场景句 / `summary` | 逐字复用 |
| `anchors.blocking` + 站位卡 | 首帧保留契约的 Preserve 清单 | 空间坐标原句进 Preserve |
| `anchors.lighting` | 光位句（贯穿全镜） | 逐字复用；视频里光不许中途变 |
| `camera`（本格机位） | 运镜指令 | Seedance：中文运镜句；H3：方括号 `[Push in]` 等，**每镜 1 个线索** |
| `in_state` → `out_state` | 动作段起—止 | 起点写 in_state 的动作相位，落点写 out_state |
| `delta` 四量表 | 视频的事件 beat | `contact`→接触点、`shift`→位移量、`phase`→动作阶段、`change`→可见结果 |
| `screen_side` | 侧位短语 | "X 在画面左侧"逐字复用，不许改写 |
| 比例锚 | 保留契约一行 | 防视频中途角色忽大忽小 |
| `anchors.negative_parts` | Seedance 负面词 / H3 `Avoid` | H3 无负面字段，按"保留契约 + 一句 Avoid"转正 |
| `ref_binding`（identity 槽） | Seedance `@图片N` / H3 参考模式 | 本格成品帧 = 首帧；角色定妆帧另占槽 |

## 二、逐格 → 逐镜的硬规则

1. **一格一镜一视频**：不把两格合并成一条视频。格子的 `delta` 就是这条视频的 beat；两格合并会把"一格一个可见推进"稀释成两拍均摊。
2. **时长按 `phase` 定**：起势/收势类 4–6 秒；接触/发力顶点类 6–8 秒；跨屋脊、跨场景的连续动作才给 10–15 秒。默认 6 秒起评。
3. **接力照旧逐字**：本镜落点句 = `out_state` 原句；下一镜起点句 = 同一句作为 `in_state`。静态接力规则在视频链上继续生效。
4. **运镜限流**：每条视频只留 1–2 个运动线索（Seedance 一个运镜句 / H3 最多一个方括号）；`camera` 字段里写的机位是起点，视频里的运动从它出发小步走。
5. **单镜只装一个事件**：`delta` 的 `change` 只有一个可见结果；想加第二个结果，回去拆格。

## 三、Seedance 2.0 版（每格一条）

模板结构（先定妆块、后提示词块，与 cinematic-prompt-master 交付契约同口径）：

```text
【定妆】（从 anchors 原句拼装：角色锚点 + 场景 + 站位 + 光位 + 一致性声明）

【提示词 · Seedance 2.0】
@图片1 提供本镜首帧构图、人物站位与光线方向，人物动作以文字为准。
{光位句逐字}。{场景句逐字}。
{in_state 的动作相位起笔}，{接触点：delta.contact}，{位移：delta.shift}，{可见结果：delta.change}，
{out_state 的落点句}。{运镜句（1 个）}。
音效：{按本格事件给 2–3 项现场声}。
负面：{negative_parts 四段原句}。
```

要点：
- `@图片1` 永远是**本格成品帧**；有角色定妆帧再占 `@图片2`，并写"图片2 仅提供角色长相与服装，不提供背景与构图"——与静态参考链同一条纪律。
- Seedance 单次 ≤15s、素材合计 ≤12、禁写实真人面部素材；动态化默认 6–8 秒，超了先拆镜。
- 音效只写画内现场声；要配乐单独说，不混在音效行。

## 四、MiniMax H3 版（每格一条，I2VA）

模板结构：

```text
【定妆】（同上，逐字）

【提示词 · MiniMax H3】
[参数] 时长 6 秒 / 2K / prompt_optimizer=false（面板或 API 设，不进提示词正文）
integrated_multimodal_description:
[Shot 1] Preserve：{角色长相/发型/服装/标志物原句}；{站位空间坐标原句}；{比例锚}；{光位句}。
动作：{in_state 相位起笔}，{contact + shift + change 组成一个事件句}，止于{out_state 落点}，[运镜方括号]。
人物{screen_side 短语逐字}；环境对动作可见反应一句（尘土/水纹/衣料受风）。
overall_soundscape: {现场声 2–3 项}
non_diegetic_music: N/A
Avoid: morphing faces, extra limbs, warped background, on-screen text
```

要点：
- **先保留、后变化**：Preserve 清单永远在动作之前；禁止重描服装细节（和首帧像素打架会烧掉身份）。
- 时间戳：单镜一条视频通常不需要 `At 00:XX.000` 切片；6 秒内装不下两个 beat 就拆镜，不硬塞时间戳。
- H3 没有负面字段：`negative_parts` 四段压缩成一句 `Avoid`（英文），其余内容全部转成正向保留句。
- prompt 上限 2000 字符；定妆块不占此额度（定妆是给用户看的一致性档案，正文只有 `[Shot 1]` 起的整块）。

## 五、动态化质检（静态门之外再加四条）

每条视频提示词在投喂前过这四条，不过不交：

1. **事件守恒**：视频里发生的事 = 该格 `delta` 的四项，没多没少；多出来的动作回去删或拆格。
2. **起点即入格**：第一帧描述与该格成品帧肉眼一致（机位、站位、相位），否则模型会自己"重新走位"。
3. **运镜守恒**：`camera` 字段说固定机位就给 `[Static shot]`，说跟拍才给 `[Tracking shot]`；禁止静态格配推拉镜头——那是把构图决定权交回给模型。
4. **音轨合规**：台词有引号有说话人且时长装得下；现场声 ≥2 项；`non_diegetic_music` 不需要就写 N/A，不写 "no music"。

## 六、动态化失败清单

- **首帧被模型重画**（人物走位、光线变了）→ Preserve 清单没放在动作之前，或重描了服装；Preserve 提前，服装句只进定妆块。
- **动作被均摊成慢爬** → 一个 15 秒镜装了两个 beat；拆成两条，每条一个事件。
- **视频中途角色忽大忽小** → 比例锚没进保留契约；补一行。
- **左右次序中途翻转** → screen_side 短语没逐字进正文；补侧位句。
- **光从中途变味**（月光变日光）→ 光位句没逐字复用或被改写；恢复 anchors.lighting 原句。
- **运镜堆叠背景抖动** → 方括号里塞了 3 个以上指令；压回每镜 1 个。
- **长台词被切** → 台词秒数超过切片时长；要么缩台词，要么加时长，要么拆镜。
- **配乐盖住台词** → 配乐进了 `overall_soundscape`；移到 `non_diegetic_music` 并写明"压底、随对话减弱"。
- **格间视频接不上** → 上一镜落点句与下一镜起点句没逐字接力；恢复 out_state/in_state 原句。
- **成品帧与首帧描述对不上** → 动态化用了旧版帧或另一格的帧；核对 `ref` 字段，重导本格成品帧。

## 七、整条链的动态化（可选交付形态）

用户要"整条片的视频脚本"时，按镜头单顺序逐格输出双平台提示词，每条之前保留该格定妆块；相邻两条的接力句逐字相同。交付物：

1. `shots.json` 追加每 shot 的 `video_prompts` 字段：`{ "seedance": "…原句…", "h3": "…原句…", "duration": 6, "ref": "SH00N" }`。
2. 拼板图照常交付（动态化不改变静态板）；视频提示词作为附加层写进同一份 JSON，可逐镜复现。
