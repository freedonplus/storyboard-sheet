# 衔接卡：让相邻两格接得上

分镜不衔接，几乎都是同一个原因：**每格独立构图，没有共用空间坐标、没有轴线、上一格结束状态没有传给下一格**。本卡把这四件事压成必填项，缺一项就不允许开图。所有锚点句集中住在镜头单顶层 `anchors` 块（单一事实源），各格从这里原句复制，校验脚本逐条比对，改一个字都会 FAIL。

## 一、三个必须先在内容卡里钉死的东西

| 项 | 作用 | 写在哪 |
|---|---|---|
| 空间蓝图 | 所有角色在同一坐标系里的固定位置，全组原句复制 | 内容卡 `blueprint` |
| 轴线与左右定则 | 机位只能在一侧，角色在画面里的左右不互换 | 内容卡 `axis` |
| 机位表 | 每镜一个机位编号，位置/高度/朝向/景别写死，相邻镜只能按表小步移动 | 内容卡 `cameras` |

## 二、空间蓝图怎么写

用**场景固定物**做坐标，不用画面方位。写完自查：把所有"左/右/前/后"字样删掉，位置仍能唯一确定。

```text
空间蓝图（全组原句复制）：小狗坐在白色停止线与斑马线第一条白条之间的沥青上，臀部离停止线约 45 厘米、离白条约 30 厘米，身体正对信号灯杆；小猫坐在小狗靠缘石一侧约 25 厘米、离停止线再远约 15 厘米的位置，坐姿、尾巴绕在前爪上；两者都在停止线之后、白条之前，不踩白条。老人从斑马线右端的缘石缺口进入路口。
```

要点：原点选一个看得见的实体（白条端点、缘石缺口、门框、桌角），每个角色给「距哪个固定物多远 + 在哪一侧 + 身体朝向谁」。

## 三、轴线规则（防"左右互换"）

- 取两个主要角色（或角色与主要目标，如信号灯）的连线为轴，**全组机位只能在这条轴的一侧**。
- 写一句左右定则并全组照抄：`在道路侧机位看，狗在左、猫在右；老人始终从猫那一侧（缘石缺口）进入。`
- 必须越轴时（侧向中景、反打），显式标注「越轴镜头」，并给它一个插入镜或视线对齐作为过渡；一格里完成，不让下一个正打镜头继续越轴。
- 相邻两镜的机位水平夹角 ≤ 90°，避免跳到近乎相反的方向。

## 四、机位表

```text
C1：停止线后方 2.5 m 沥青上，离地 20 cm，水平朝信号灯杆，广角，运动：沿白条方向慢推 20 cm。
C2：狗猫侧后方 1.2 m，离地 60 cm，仰角约 20°，朝灯与倒计时屏，近景，运动：右摇 10° 后下摇 8°。
C3：停止线后方 3.5 m，离地 120 cm，水平朝缘石缺口（与 C1 约 90°），中景，运动：沿停止线方向横移 30 cm。
```

相邻镜变化不得超过：高度差一个身位、景别连跳两级（全景直跳近景必须插中景）、夹角 90°。

## 五、尾态 / 首态接力（最硬的一条）

每格写两条状态，镜头单 JSON 用 `in_state` / `out_state`：

```text
SH001 out_state：狗坐姿不动、视线上仰对准红灯；猫尾巴绕前爪、头已转向信号灯；两者仍在蓝图原位，未移动。
SH002 in_state：（必须与 SH001 的 out_state 逐字相同）
```

硬规则：**第 N 格 out_state 与第 N+1 格 in_state 逐字一致**，禁止重写、禁止"基本一致"。位置、朝向、动作相位、接触点、表情强度五项都要落字。换场必须显式标 `scene_break: true`（参考图链同时断开、重开首格），不允许默默断链；校验脚本对未标记的断链直接 FAIL。

## 六、切点类型（写清接住什么）

| 类型 | 用法 | 写法 |
|---|---|---|
| 动作切 | 动作未完时切 | 接住左脚刚落地的那一帧 |
| 同构图跳切 | 时间省略 | 同一机位同一构图，只换时间状态 |
| 视线切 | 反应镜 | 接住视线定住的人／物 |
| 声音先行切 | 下一格先出声 | 脚步声先入，画面后到 |
| 硬切 | 默认 | 接住上一格已完成的动作 |

## 七、参考图链（执行层面的最大杠杆）

生成顺序按机位表串行，不要一次并行全部格：

1. 先出 C1 首格（定下空间、比例、光线、角色外观）。
2. 后续格把**上一格成品**作为参考图传入，指令固定写：`只参考空间布局、角色比例、地面关系与光线方向，不照抄构图`。
3. 每格仍保留四件套锚点句（角色锚点 + 空间蓝图 + 光位 + 画幅）。
4. 只限同一场戏内传递；换场就断链，用新首格重开。

## 八、比例锚（防角色忽大忽小）

选一个场景固定尺寸物写进每格：白条宽约 45 厘米、缘石高约 15 厘米、护栏立柱间距约 1.2 米。角色尺寸用锚换算：`狗高约 20 厘米，约白条宽的一半`。这样即使景别变化，观众也能确认是同一个空间。

## 九、屏幕侧位锁定（防"一格在左、一格跑到右"）

站位漂移有两个变量：角色在空间的实位（由 `blueprint`/`blocking` 锁）、以及**本机位下谁在画面哪一边**（由 `axis` 只说"机位在同侧"并不够）。只锁空间坐标不锁屏幕侧位，机位一变或模型自己重排构图，角色就翻到另一边。

做法：每格在镜头单里写 `screen_side`，只列本格真正可见的角色，取值只有 `left` / `center` / `right`：

```json
"screen_side": { "小狗": "left", "小猫": "right" }
```

每格 Prompt 必须原句出现对应短语：`小狗在画面左侧`、`小猫在画面右侧`（`center` 写 `小狗在画面中部`）。短语由 `screen_side` 直接生成，逐格原句复制，不许各格改写为"左边""左半边""偏左"。

硬规则：

1. **同场相邻格之间，任意两个都出镜的角色，左右次序必须保持不变。** 校验脚本对次序翻转直接 FAIL。
2. 反打／过肩确需翻转时，该格标 `reverse_shot: true`，并在 `cut_in` 写明过渡（"反打：接住狗抬头看向猫的视线"）。一组反打只能成对出现，下一格必须切回原侧位，不允许连续两格都反。
3. 单角色独占画面时不要写暧昧方位，直接给 `center` 或按构图写死一侧；下一格换景别仍沿用同一侧。
4. 机位表 `pos` 只说明"机位在哪"，`screen_side` 才说明"谁在画面哪边"，两者不能互相替代，也不能互相推导。

## 十、双主体参考绑定（防"两个主体的参考方向搞反"）

一次传多张参考图时，模型并不知道哪张对应哪个主体，就会把身份、朝向、服装串位——这是"两只动物的参考搞反"的根因。

做法：每格在镜头单里写 `ref_binding`，把槽位与主体一一绑死：

```json
"ref_binding": [
  { "slot": "图片1", "subject": "小狗", "role": "identity" },
  { "slot": "图片2", "subject": "小猫", "role": "identity" },
  { "slot": "图片3", "subject": "SH003", "role": "layout" }
]
```

Prompt 必须逐槽写固定句式：

```text
图片1 仅提供小狗的毛色、脸型、体型与绿色项圈，不提供背景与构图。
图片2 仅提供小猫的虎斑纹、耳形与体型，不提供背景与构图。
图片3 仅提供 SH003 的空间布局、地面关系与光线方向，不照抄构图。
```

硬规则：

1. 槽位编号必须与工具实际收到的图片顺序一致（`图片1` = 第一张）。
2. 一个槽位只绑一个主体；一个主体可以占多个槽位（identity 与 layout 分开），但必须写明各自主责。
3. 禁止"一张图同时指代两个主体"再靠文字大概对应；身份素材与构图素材必须分槽。
4. 方向反了通常是"把上一格整幅画面当身份图"造成：`identity` 只传身份素材，`layout` 另开槽。

## 十一、穿模、融合与主体分离

穿模几乎都是"两个主体的轮廓没有被要求分开"造成的，靠重出治不了，必须同时写正向分离约束与负向禁令。

正向（每格都要有）：

- **主体分离句**：两个主体之间保留可见间隙（"两者之间至少留出半个身位"），前后层次写死一项（谁在前、谁被谁部分遮挡）。
- **接触面与阴影**：各自独立的接触阴影落在地面同一侧，不出现共用一团阴影。
- **地面关系**：足部／臀部落在同一地平面，不悬空、不埋入地面、不站在白条边缘之外。
- **复杂动作写明接触点**：抱、压、摔、抢夺必须写"接触点在哪、哪部分被压住"，只写"压住"不写接触点必然穿模。

负向（收进 `anchors.negative_parts`）：肢体互相穿插、身体融合粘连、多余手臂手指腿爪、道具或背景物体穿过身体、衣物穿过身体、角色悬浮、影子朝向与光位矛盾。

## 十二、交付前自查

自查分两层：先跑机器，再过人眼。

机器校验（`scripts/validate-shots.ps1`，FAIL 即阻断）：

- 相邻格 `out_state` 与下一格 `in_state` 是否逐字相等
- 时间区间是否首尾相接、镜头号是否连续
- 每格 `prompt` 是否原句包含全部 anchors 与出场角色锚点
- 机位引用是否存在、参考图链是否只指向更早的格
- 每格 `screen_side` 是否齐全、只列本格可见角色，`prompt` 是否原句含侧位短语
- 同场相邻格的角色左右次序有无翻转（除显式 `reverse_shot: true`）
- `anchors.negative_parts` 四段是否齐全，且每格 `prompt` 原句含四段
- `ref_binding` 每个槽位是否绑定了单主体、`prompt` 是否逐槽写了用途句

人眼复核（机器查不出的语义问题）：

- 角色左右位置是否全组一致（有没有一格狗跑到右边）
- 反打是否成对出现、下一格是否已切回原侧位
- 两个主体之间有没有可见间隙，是否出现身体粘连、轮廓融合、肢体穿插、道具穿过身体
- 相邻机位夹角是否 ≤ 90°，高度差是否超一个身位
- 同一场景物（白条、缘石、护栏）在两格中形态是否一致
- 视线是否指向同一目标（看灯就全看灯，别一格看灯一格看人）
- 光位句是否同一句，色温有没有偷偷变暖
- 比例锚是否每格都在，角色尺寸有无跳变
- 状态卡是否全组同一句，灯态／数字／天气有无自相矛盾

## 十三、溯源回写（高溯源）

每格定稿后立刻把四样写回该 shot，缺一项不算完成：

| 字段 | 内容 | 作用 |
|---|---|---|
| `prompt` | 提交给生图模型的完整原句，一字不改（含全部锚点句与入格/出格状态） | 任何人拿 JSON 可逐格复现 |
| `ref` | 参考图链：`null`=首格/断链，`"SH003"`=单参考，`"SH001+SH003"`=双参考 | 定位一致性问题的传播路径 |
| `seed` | 生图工具返回的种子；工具不给就保持 `null` 并在 `qa` 注明 | 精确复现 |
| `qa` | 单格质检结论：通过／重出次数与原因／遗留风险 | 穿帮追责到具体格 |
| `screen_side` | 本格可见角色在画面的左右侧位 | 定位左右翻转的责任格 |
| `ref_binding` | 每个图片槽位绑定的主体与用途 | 定位"参考搞反"的槽位 |

穿帮排查顺序：看出问题的格 → 读它的 `ref` 找到参考来源 → 对比两格的 `prompt` 哪句锚点被改了 → 修 anchors 或该格 Prompt → 只重出受影响的格与其下游（参考图链上挂在它后面的格都要复核）。

## 十四、可变状态卡（灯态／时间／天气／门）

同一场戏里会变化、且观众会读出含义的对象，必须给一句固定状态并全组原句复制。最常穿帮的是信号灯。

| 对象 | 正确形态 | 常见穿帮 |
|---|---|---|
| 车辆信号灯（面向本车道） | 三圆盘（红／黄／绿），亮的是纯色圆盘或绿色直行箭头，与行人灯分开、朝向车流 | 圆盘里画人形；红灯亮却像绿灯；灯与车流方向矛盾 |
| 行人信号灯 | 红＝**站立不动**人形；绿＝**行走**人形；灯箱多为方形、比车辆灯小 | 红色行走人形；绿灯里画站立人；圆形大灯箱里塞人形 |
| 行人倒计时屏 | 数字颜色与服务灯色一致；红灯时显示剩余红秒数 | 红灯配绿色数字；数字与灯分属不同方向 |
| 车道箭头／地面标线 | 与当前通行权一致 | 直行绿灯却配“禁止直行”标牌 |
| 时间／天气／水位／门 | 一句固定状态，跨格不改 | 一格白天一格黄昏；一格关灯一格开灯 |

硬规则：

1. **通行权只能有一个结论**。写“行人红灯＋车辆直行绿灯”时，必须补一句“车辆正沿本车道直行通过路口”，否则灯与车流会打架。
2. **写清哪盏面向谁**：面向本车道车辆 / 面向过街行人 / 面向对向车道，不能笼统写“信号灯”。
3. **不允许自造符号**：圆盘里画人形、红色行走人形、绿灯配红数字，一律视为穿帮。
4. 状态卡与站位卡、光位句一起进四件套，逐格原句复制，统一收进 `anchors.props` 块。

## 十五、格间推进四量表（衔接的唯一硬指标）

故事板只作参考，风格可以放后面；观众判“接不上”的依据只有一件事：**后一格比前一格多了什么**。每格必须把这件事写成四个量，收进 shot 的 `delta`：

| 量 | 必须写成 | 示例（15s 短打） |
|---|---|---|
| `contact` 接触点 | 本格动作落在谁身上哪个部位；无接触就写“无接触” | 反派左拳拳面与主角左小臂中段外侧 |
| `shift` 位移 | 相对上一格的位置变化，必须带数字 | 间距从两步半拉到四步 / 双方前臂各退半寸 |
| `phase` 相位 | 起势／发力顶点／接触／收势／余势／定格 | 撞击顶点 |
| `change` 可视结果 | 这一格观众新看到的结果，**与 `out_state` 同文** | 主角左小臂横在胸前、反派左拳砸在小臂中段… |

三条硬规则（`validate-shots.ps1` 强制执行）：

1. **四量缺一 FAIL**；`change` 必须是 `out_state` 的子串，否则 FAIL——可视结果没落在出格状态，等于下一格接不到。
2. **相邻两格四量全同 FAIL**：换了张图但事件没动，是最典型的“假衔接”。
3. **相邻格动作段 2-gram 相似度 > 0.5 FAIL**：把 `本镜头：` 到 `出格状态：` 之间的文字（去掉机位描述前缀）做字符二元组 Jaccard 比对，措辞高度重合即判重复。改的办法不是换词，而是**换接触点、换位移量、换相位或换景别机位**。

配套的景别台阶：1 大远景／2 远景／3 全景／4 中景／5 中近景／6 近景／7 特写／8 大特写，**相邻差 ≥3 判连跳两级 FAIL**，要跳就在中间补一格过渡景别。

写法建议：

- 一组连续动作按“起势 → 靠近 → 接触 → 加力 → 收势 → 拉开”排相位，每格相位不同，`change` 自然不同。
- 量化位移是最好用的差异化手段：间距三步→两步半→四步、前臂各退半寸、后跟离地约三厘米、头部右移半个头宽、上身前倾超三十度。数字一变，动作段相似度就降下来了。
- 特写/大特写格容易“只剩一个主体”，必须在动作句里用服装特征与画面侧位把两个主体都点出来，否则判废。
