# 故事板提示词模板

## 一、内容卡

写 Prompt 前先填满，缺项由 Agent 依故事补全，不向用户发问卷。

| 字段 | 填写要求 |
|---|---|
| 片名与题材 | 一句话，例：忍者屋顶潜袭 · 夜战动作 |
| 角色锚点 | 3–6 条不可变特征：服装配色、头巾/面罩样式、装备、体型。收进 `anchors.characters`，全组逐格原句复制 |
| 场景 | 地点、主要材质、远景层次、高度关系，收进 `anchors.scene` |
| 站位卡 | 每个角色**相对场景固定物**的坐标，收进 `anchors.blocking`，逐格原句复制，见 §一之二。禁用"前景/后景/左侧"描述站位 |
| 空间蓝图与机位表 | 一句到底的空间坐标（`anchors.blueprint`）+ 轴线与左右定则（`anchors.axis`）+ 每镜机位编号（`cameras` 表：位置/高度/朝向/景别/运动），见 [continuity.md](continuity.md) |
| 状态卡 | 会变且观众会读含义的对象（信号灯/倒计时/时间/天气/门）给一句固定状态，与比例锚合并收进 `anchors.props`；灯态必须符合真实语义，见 [continuity.md](continuity.md#十可变状态卡灯态时间天气门) |
| 光影与质感 | 主光方向＋色温＋辅光（`anchors.lighting`）＋颗粒/景深（`anchors.style`），全组固定 |
| 画幅与格数 | 每格比例（默认 16:9）＋格数（4/6/8/9）＋是否要标题卡 |
| 镜头单 | 每格：镜头号、时长、镜头名、景别、机位编号、出场角色 `cast`、动作因果、入格/出格状态、切点承接 |
| 禁止项 | 文字/字幕/水印/编号/边框为固定项，按题材追加，收进 `anchors.negative` |

### 一之二、站位卡（解决"站位一直变来变去"）

站位漂移的根因是每格各自描述位置。做法：先在内容卡里定义一张**以场景固定物为基准**的站位锚点，之后每格原句复制，只改动作与景别。

| 要求 | 说明 |
|---|---|
| 基准物 | 只用场景里的实体：停止线、斑马线第 N 条白线、缘石、台阶、门框、桌沿、护栏立柱、招牌下沿。禁止用"画面左侧""前景""右侧三分之一"这类与机位耦合的说法 |
| 距离量化 | 给相对量与方向：站在停止线后侧约 40 厘米、在缘石内侧、臀部距第一块白线右缘约 30 厘米 |
| 朝向量化 | 面朝信号灯方向、侧身 45° 对街、背对门框 |
| 角色间关系 | 谁在谁的哪一侧、相距多少，同组固定不变 |
| 机位也定位 | 机位写成"贴在停止线延长线的沥青上方、朝缘石方向"，后才能说明某角色在画面什么位置 |

站位锚点句示例（多角色同场）：

```text
站位锚点（全组原句复制）：小狗坐在白色停止线后侧约 40 厘米的沥青上，身体正对信号灯方向，位于斑马线左端白条延长线偏左约半个身位，前爪并拢；小猫坐在小狗右侧约 25 厘米、比小狗靠后约 15 厘米处，尾巴绕在前爪上。两只动物都在停止线之后、缘石之前，都不踩到斑马线白条。
```

每格只在此锚点上追加"本镜唯一变化"：狗抬头、猫前倾、老人从缘石侧迈步等。动作涉及位移时，写清位移**相对锚点**的方向与距离（"向前踏出约一步、越过停止线"），不写"走向画面左边"。

## 二、单格分镜图 Prompt 模板

推荐路线：逐格生成再拼板。一致性最好、格内细节最足。

```text
电影分镜剧照，16:9 横幅构图。{全局质感句：黑白灰阶为主、月光处冷蓝点缀、35mm 胶片颗粒、写实电影质感}。
主要人物：{角色锚点句，逐格原句复制}。
场景：{地点与材质句}。
站位：{站位锚点句，逐格原句复制}。
比例锚：{场景固定尺寸物＋角色尺寸换算}。
状态卡：{会变对象的固定状态句，逐格原句复制；灯态写清哪盏面向谁}。
入格状态：{上一格 out_state 逐字复制}。
本镜头：{机位编号}＋{景别}＋{机位与运动}＋{主体动作的起点、路径、接触点、结果}＋{光影落点}＋{景深与焦点}。
出格状态：{位置／朝向／动作相位／接触点／表情强度五项}。
画面中不出现任何文字、字幕、水印、编号或边框。
```

示例（夜战动作 · 踏击镜）：

```text
电影分镜剧照，16:9 横幅构图。黑白灰阶为主、月光处冷蓝点缀、35mm 胶片颗粒。
主要人物：深靛蓝近黑紧身忍装、头巾只露双眼、护腕绑腿、腰侧布囊、背后短刀、体型精瘦。
场景：月夜瓦屋顶平台，屋脊、瓦当、矮墙，远景城市灯火。
本镜头：中景转贴地低角，忍者自上方急坠，膝盖与肘部同时砸在敌人肩背，敌人（深灰作战服、轻便护具、无面罩）被压得贴向瓦面、手臂脱力摊开，瓦片呈放射状崩开、灰尘碎屑沿坡面滑落；月光自左后方高位射入，瓦面出现强烈明暗分界，扬尘掠过前景，画面带轻微震动感。
画面中不出现任何文字、字幕、水印、编号或边框。
```

一致性四件套，每格必须原样复制：同一角色锚点句（仅出场角色，按 `cast` 声明）＋ 同一站位锚点句 ＋ 同一光位句 ＋ 同一画幅参数（1536×864）。蓝图、轴线、比例与状态、禁止项同理——八句都从 `anchors` 块原句取，校验脚本逐条做子串比对。

## 三、整板九宫格 Prompt（快速看概念用）

一次出图适合过方案，不适合定稿：跨格人物容易变脸、格内细节被压缩。

```text
横版 3×3 故事板拼板，整体 16:9，九格等分，每格是一幅 16:9 电影分镜画面，格与格之间用 6px 深灰分隔线，整体深色背景。
统一要求：同一位{角色锚点句}贯穿全部画面；全部为{同一光位句}；统一{质感句}；每格构图不重复、景别与机位逐格变化。
第 1 格：{镜头内容}
第 2 格：{镜头内容}
……
第 9 格：深色标题卡，写“{片名}”与“STORYBOARD / {格数} SHOTS / {时长} / {比例}”，不出现其他文字。
```

## 四、动作与运镜写法

| 要写清的 | 写法示例 |
|---|---|
| 景别 | 极近特写／近景／中景／中全景／全景／大远景 |
| 角度 | 贴地低角、顶视俯拍、过肩、侧向平视、背后跟拍、45° 斜向下 |
| 运动 | 固定、横摇跟随、上摇跟随、侧向弧线环绕、缓推、快速拉出、手持跟拍 |
| 速度 | 正常速度、极短减速停留（只给动作顶点）、连续加速（只给冲刺段） |
| 接触点 | 膝肘同时砸在肩背、手里剑钉入肩背护具、指尖捏住杯沿 |
| 结果 | 敌人被压得贴向瓦面、瓦片放射崩开、扬尘掠过前景 |
| 切点 | 奔跑未减速时切，后镜接刚蹬离的瞬间／视线定住后切，后镜接同一只手伸向腰侧 |

## 五、质检门（单格）

每出一格，对照这十条过目。**任何一条不过，原地重出这一格，不带病进入拼板**：

1. 脸型/服装/装备对得上角色锚点句（逐条对，不是"看起来像"）
2. 站位落在蓝图坐标上（相对固定物的距离、侧位、朝向都对）
3. 角色画面左右符合轴线定则，没互换
4. 尺寸合比例锚（和固定尺寸物换算一致，没忽大忽小）
5. 状态卡语义正确（灯态/数字/天气/门，见 continuity.md 可变状态卡）
6. 光位色温与光位句一致，没偷偷变暖/换方向
7. 入格状态接住了上一格出格状态（位置/朝向/动作相位/接触点/表情强度）
8. 一格只有一个主要动作变化
9. 无文字、字幕、水印、编号、边框
10. 与同场前几格并排看，是"同一个空间"而不是"相似的空间"

重出策略：

- 只修出错的那一项，锚点句一字不动。
- 同格重出两次仍漂移 → 把首格成品一起传入做双参考（`ref` 写成 `"SH001+SH00N"`）。
- 双参考仍不行 → 降级景别（近景/特写比全景稳），或把该动作拆成两格。
- 每格质检结论与重出原因写回该 shot 的 `qa` 字段。

## 六、失败清单

- 角色逐格变脸 → 角色锚点句被改成"同上"或漏写，恢复原句复制；仍漂移则以首格为参考图逐格传入；双参考仍漂移则降级景别。
- **站位逐格漂移（同一角色一格在路面、一格在缘石）** → 站位锚点句被各格自写，或用了"前景/后景/左侧"这类与机位耦合的说法；改回 `anchors.blocking` 同一句锚点，位移只写相对锚点的方向与距离。
- **相邻格接不上（像两个故事的两张图）** → 缺空间蓝图/轴线/尾态首态接力；按 [continuity.md](continuity.md) 补齐：全组同一蓝图、机位同侧小步移动、上一格 out_state 与下一格 in_state 逐字相等、比例锚同句；跑 `validate-shots.ps1` 定位是哪一格断的。
- 角色左右互换 → 越轴了，机位移到轴线另一侧；把机位表拉回同一侧，或显式标注越轴并给过渡镜。
- 角色忽大忽小 → 没写比例锚，用场景固定尺寸物做换算后重出。
- **灯态穿帮（行人红灯画成红色行走人形／圆形车灯里塞人形／红灯配绿色数字）** → 状态卡缺失或自造符号；按 [continuity.md](continuity.md#十可变状态卡灯态时间天气门) 的灯态规范重写一句状态卡并全组复制，同时补"车辆正沿本车道直行通过路口"把通行权说圆。
- 光位跳变 → 光位句被各格自写，统一回 `anchors.lighting` 同一句。
- **同一空间不像同一空间** → 蓝图/状态卡/场景固定物形态没逐格复制，或参考图链断在中途；按 `ref` 字段回溯断链点，从断点格起重出。
- 编号乱码 → 让模型画了编号，删掉并在拼板阶段叠字。
- 一格塞多步动作 → 拆成相邻两格，各保留一个主要变化。
- 画面被拉变形 → 拼板时未按 cover 裁切，检查脚本的裁切逻辑而不是拉伸参数。
- 格子与叙事错位 → 镜头单按画面美观拆而非按事件拆，回到内容事件重排。
- **交付后无法复现某一格** → 溯源字段没回写；`prompt`/`seed`/`ref`/`qa` 补齐前不算交付完成。
