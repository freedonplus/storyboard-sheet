# 故事板提示词模板

## 一、内容卡

写 Prompt 前先填满，缺项由 Agent 依故事补全，不向用户发问卷。

| 字段 | 填写要求 |
|---|---|
| 片名与题材 | 一句话，例：忍者屋顶潜袭 · 夜战动作 |
| 风格预设 | 可选，开板最多问一次：`realistic` 原装写实（默认兜底）／`line_bw` 黑白线稿／`graphite` 灰阶素描／`manga_tone` 漫画网点／`cel2d` 赛璐璐／`guoman3d` 国漫 3D／`aaa_cg` 3A CG／`watercolor` 水彩淡彩，见 §七。**不选不影响开工，风格不参与衔接校验** |
| 衔接四量表 | 每格相对上一格到底改了什么：`contact` 接触点／`shift` 位移（带数字）／`phase` 相位／`change` 可视结果（与 `out_state` 同文），收进该格 `delta`，见 [continuity.md](continuity.md#十五格间推进四量表衔接的唯一硬指标) |
| 角色锚点 | 3–6 条不可变特征：服装配色、头巾/面罩样式、装备、体型。收进 `anchors.characters`，全组逐格原句复制 |
| 场景 | 地点、主要材质、远景层次、高度关系，收进 `anchors.scene` |
| 站位卡 | 每个角色**相对场景固定物**的坐标，收进 `anchors.blocking`，逐格原句复制，见 §一之二。禁用"前景/后景/左侧"描述站位 |
| 空间蓝图与机位表 | 一句到底的空间坐标（`anchors.blueprint`）+ 轴线与左右定则（`anchors.axis`）+ 每镜机位编号（`cameras` 表：位置/高度/朝向/景别/运动），见 [continuity.md](continuity.md) |
| 状态卡 | 会变且观众会读含义的对象（信号灯/倒计时/时间/天气/门）给一句固定状态，与比例锚合并收进 `anchors.props`；灯态必须符合真实语义，见 [continuity.md](continuity.md#十四可变状态卡灯态时间天气门) |
| 屏幕侧位 | 本机位下每个可见角色在画面的哪一边，收进该格 `screen_side`（`left`/`center`/`right`），相邻格不允许翻转，见 [continuity.md](continuity.md#九屏幕侧位锁定防一格在左一格跑到右) |
| 参考图绑定 | 每张参考图对应哪个主体、什么用途，收进该格 `ref_binding`（`slot`/`subject`/`role`），一槽一主体，见 [continuity.md](continuity.md#十双主体参考绑定防两个主体的参考方向搞反) |
| 光影与质感 | 主光方向＋色温＋辅光（`anchors.lighting`）＋颗粒/景深（`anchors.style`），全组固定 |
| 画幅与格数 | 每格比例（默认 16:9）＋格数（4/6/8/9）＋是否要标题卡 |
| 镜头单 | 每格：镜头号、时长、镜头名、景别、机位编号、出场角色 `cast`、动作因果、入格/出格状态、切点承接 |
| 禁止项 | 文字/字幕/水印/编号/边框为固定项，按题材追加，收进 `anchors.negative` |

### 一之二、站位卡（解决"站位一直变来变去"）

站位漂移的根因是每格各自描述位置。做法：先在内容卡里定义一张**以场景固定物为基准**的站位锚点，之后每格原句复制，只改动作与景别。

| 要求 | 说明 |
|---|---|
| 基准物 | 只用场景里的实体：停止线、斑马线第 N 条白线、缘石、台阶、门框、桌沿、护栏立柱、招牌下沿。禁止用"画面左侧""前景""右侧三分之一"这类与机位耦合的说法 |
| 距离量化 | 给相对量与方向：站在停止线后侧约 40 厘米、在缘石内侧、臀部距第一块白线右缘约 30 厘米 |
| 朝向量化 | 面朝信号灯方向、侧身 45° 对街、背对门框 |
| 角色间关系 | 谁在谁的哪一侧、相距多少，同组固定不变 |
| 机位也定位 | 机位写成"贴在停止线延长线的沥青上方、朝缘石方向"，后才能说明某角色在画面什么位置 |

站位锚点句示例（多角色同场）：

```text
站位锚点（全组原句复制）：小狗坐在白色停止线后侧约 40 厘米的沥青上，身体正对信号灯方向，位于斑马线左端白条延长线偏左约半个身位，前爪并拢；小猫坐在小狗右侧约 25 厘米、比小狗靠后约 15 厘米处，尾巴绕在前爪上。两只动物都在停止线之后、缘石之前，都不踩到斑马线白条。
```

每格只在此锚点上追加"本镜唯一变化"：狗抬头、猫前倾、老人从缘石侧迈步等。动作涉及位移时，写清位移**相对锚点**的方向与距离（"向前踏出约一步、越过停止线"），不写"走向画面左边"。

## 二、单格分镜图 Prompt 模板（正向块 + 负向块）

推荐路线：逐格生成再拼板。一致性最好、格内细节最足。Prompt 一律写成**正向块＋负向块**两段，正向块十行、顺序不许换（顺序一乱，模型常常先画背景后摆角色，站位就跟着漂）。

```text
【正向】
1 媒介与画幅：电影分镜剧照，16:9 横幅构图。
2 全局质感：{anchors.style 原句复制}
3 主体绑定：图片1 仅提供{主体A}的{毛色/脸型/服装/体型/项圈}，不提供背景与构图；图片2 仅提供{主体B}的{…}，不提供背景与构图（按 ref_binding 逐槽写，一槽一主体）
4 角色锚点：{anchors.characters 原句复制，仅 cast 内角色}
5 场景：{anchors.scene 原句复制}
6 站位：{anchors.blocking 原句复制}
7 屏幕侧位：{screen_side 生成的短语}，例如“小狗在画面左侧、小猫在画面右侧”
8 比例锚与状态卡：{anchors.props 原句复制}
9 入格状态＋本镜动作：{上一格 out_state 逐字复制}＋{机位编号}{景别}{运动}＋{动作起点、路径、接触点、结果}＋{光影落点、景深焦点}
10 出格状态：{位置／朝向／动作相位／接触点／表情强度五项}
11 本格变化量：接触点 {delta.contact}；位移 {delta.shift}；相位 {delta.phase}；可视结果 {delta.change}

【负向】
基础：{anchors.negative_parts.base}
解剖：{anchors.negative_parts.anatomy}
几何：{anchors.negative_parts.geometry}
分离：{anchors.negative_parts.separation}
```

第 11 行是**衔接锚**：把这一格相对上一格的推进写在同一份 Prompt 里，模型才知道“这一张要跟上一张不一样”。`delta.change` 必须与该格 `out_state` 同文，校验器做子串比对。

四段负向是硬要求，缺一段视为没写负向：

| 段 | 管什么 | 怎么写 |
|---|---|---|
| `base` | 文字、字幕、水印、编号、边框、卡通化、题材禁忌 | 固定句，全组同一句 |
| `anatomy` | 多余手臂手指、重复腿爪、肢体互相穿插、身体融合、头身错位 | 明确列"不许出现哪些畸形" |
| `geometry` | 道具或背景物体穿过身体、衣物穿身、悬浮、足底离地、影子朝向矛盾 | 按本场实际物件点名，如"瓦片、屋檐、护栏不许穿过人物" |
| `separation` | 两个主体粘连、轮廓融合、共用一团阴影 | 写清"两者之间留出可见间隙、各自有独立接触阴影" |

示例（双主体 · 低机位对话镜）：

```text
【正向】
电影分镜剧照，16:9 横幅构图。自然阴天漫射日光、写实 3D CG、35mm 细颗粒、冷灰低饱和。
图片1 仅提供小狗的棕黄毛色、圆脸、矮胖体型与绿色皮质项圈，不提供背景与构图。 图片2 仅提供小猫的米白灰虎斑、橘黄尖耳、圆脸大眼与体型，不提供背景与构图。
主要人物：小狗，棕黄与米白毛色、圆脸短腿、绿色皮质项圈、约 20 厘米高的圆润矮胖体型。小猫，米白灰底配深灰虎斑、圆脸短耳、橘黄尖耳、约 25 厘米高的圆脸体型。
场景：城市路口缘石前的地面砖与沥青，背后是斑马线白条与信号灯杆下段，远景虚化。
站位：小狗坐在缘石前侧地面、离缘石约 40 厘米；小猫坐在小狗靠缘石一侧约 25 厘米处；两者都不踩白条。
小狗在画面左侧、小猫在画面右侧。
比例锚：白条宽约 45 厘米，狗高约白条的一半，猫略高于狗；灯态为行人红灯、车辆直行绿灯，车辆正沿本车道通过路口。
小狗嘴微张、身体侧对小猫；机位 C1 贴地 20 厘米、与两只眼睛齐平、缓推 15 厘米。
出格状态：小狗嘴微张说完第一句、视线上抬；小猫头微侧、尾巴绕前爪；两者仍在蓝图原位。
【负向】
基础：画面中不出现任何文字、字幕、水印、编号或边框，不做卡通化。
解剖：不出现多余的手臂、手指、腿脚或重复肢体，不出现肢体互相穿插、身体融合、头部与躯干错位。
几何：不出现道具与身体穿模、瓦片与护栏穿过身体、角色悬浮或足底离地、影子与光位矛盾。
分离：两个主体之间保留可见间隙与各自的接触阴影，前后层次清楚，不允许粘连或轮廓融合。
```

一致性清单，每格必须原样复制：`anchors` 八句（仅 `cast` 内角色锚点）＋ `negative_parts` 四段 ＋ `screen_side` 侧位短语 ＋ `ref_binding` 逐槽绑定句 ＋ 画幅参数（1536×864）。校验脚本逐条做子串比对，改一个字都会 FAIL。

## 三、整板九宫格 Prompt（快速看概念用）

一次出图适合过方案，不适合定稿：跨格人物容易变脸、格内细节被压缩。

```text
横版 3×3 故事板拼板，整体 16:9，九格等分，每格是一幅 16:9 电影分镜画面，格与格之间用 6px 深灰分隔线，整体深色背景。
统一要求：同一位{角色锚点句}贯穿全部画面；全部为{同一光位句}；统一{质感句}；每格构图不重复、景别与机位逐格变化。
第 1 格：{镜头内容}
第 2 格：{镜头内容}
……
第 9 格：深色标题卡，写“{片名}”与“STORYBOARD / {格数} SHOTS / {时长} / {比例}”，不出现其他文字。
```

## 四、动作与运镜写法

| 要写清的 | 写法示例 |
|---|---|
| 景别 | 极近特写／近景／中景／中全景／全景／大远景 |
| 角度 | 贴地低角、顶视俯拍、过肩、侧向平视、背后跟拍、45° 斜向下 |
| 运动 | 固定、横摇跟随、上摇跟随、侧向弧线环绕、缓推、快速拉出、手持跟拍 |
| 速度 | 正常速度、极短减速停留（只给动作顶点）、连续加速（只给冲刺段） |
| 接触点 | 膝肘同时砸在肩背、手里剑钉入肩背护具、指尖捏住杯沿 |
| 结果 | 敌人被压得贴向瓦面、瓦片放射崩开、扬尘掠过前景 |
| 切点 | 奔跑未减速时切，后镜接刚蹬离的瞬间／视线定住后切，后镜接同一只手伸向腰侧 |

## 五、质检门（单格）

每出一格，对照这十三条过目。**任何一条不过，原地重出这一格，不带病进入拼板**：

1. 脸型/服装/装备对得上角色锚点句（逐条对，不是"看起来像"）
2. 站位落在蓝图坐标上（相对固定物的距离、侧位、朝向都对）
3. 角色画面左右符合轴线定则，没互换
4. 尺寸合比例锚（和固定尺寸物换算一致，没忽大忽小）
5. 状态卡语义正确（灯态/数字/天气/门，见 continuity.md 可变状态卡）
6. 光位色温与光位句一致，没偷偷变暖/换方向
7. 入格状态接住了上一格出格状态（位置/朝向/动作相位/接触点/表情强度）
8. 一格只有一个主要动作变化
9. 无文字、字幕、水印、编号、边框
10. 与同场前几格并排看，是"同一个空间"而不是"相似的空间"
11. 屏幕侧位与本格 `screen_side` 一致，且与同场上一格的角色左右次序没有翻转（反打格必须标 `reverse_shot: true`，且下一格已切回原侧位）
12. 无穿模与融合：两个主体之间有可见间隙、无粘连、无多余的腿爪手指、道具与背景物体没有穿过身体、角色没有悬浮
13. **本格相对上一格有肉眼可见的新变化**：把相邻两格并排看，能一眼说出“这一格多了什么”——接触点变了、距离变了、相位变了（起势→接触→收势）、姿态或表情变了；两格看起来像同一个动作的两个角度，判不过重出。`cast` 里点名的角色缺席、只剩一个主体对着空气做动作，也判废。

重出策略：

- 只修出错的那一项，锚点句一字不动。
- **主体缺席/只剩单主体**：在动作句里点明“画面左侧是{A 的服装特征}、画面右侧是{B 的服装特征}、两者在画面中央相撞”，用服装与侧位把两个主体都拉回画面；必要时把景别放宽一档（特写→中近景）。
- 同格重出两次仍漂移 → 把首格成品一起传入做双参考（`ref` 写成 `"SH001+SH00N"`）。
- 双参考仍不行 → 降级景别（近景/特写比全景稳），或把该动作拆成两格。
- 每格质检结论与重出原因写回该 shot 的 `qa` 字段。

## 六、失败清单

- 角色逐格变脸 → 角色锚点句被改成"同上"或漏写，恢复原句复制；仍漂移则以首格为参考图逐格传入；双参考仍漂移则降级景别。
- **站位逐格漂移（同一角色一格在路面、一格在缘石）** → 站位锚点句被各格自写，或用了"前景/后景/左侧"这类与机位耦合的说法；改回 `anchors.blocking` 同一句锚点，位移只写相对锚点的方向与距离。
- **相邻格接不上（像两个故事的两张图）** → 缺空间蓝图/轴线/尾态首态接力；按 [continuity.md](continuity.md) 补齐：全组同一蓝图、机位同侧小步移动、上一格 out_state 与下一格 in_state 逐字相等、比例锚同句；跑 `validate-shots.ps1` 定位是哪一格断的。
- **换了张图但事件没动（相邻格看起来是同一动作的两个角度）** → `delta` 四量表四项全同或动作段几乎同文；校验器报“动作描述高度重复”时，改本格动作的接触点、位移量或相位，或改景别/机位重出，不要只调 Prompt 措辞。
- **景别忽远忽近（中景直接跳大特写再跳回中近景）** → 景别台阶连跳；按 1–8 台阶在中间补一格过渡景别，或把跳级的那格改成相邻档位；校验器对相邻差 ≥3 直接 FAIL。
- **该出场的角色没入画（反派整个缺席、只剩主角对着空气出拳）** → 动作句没点明两个主体的服装特征与画面位置；用“画面左侧是{A 服装}、右侧是{B 服装}、中央相撞”重写，并用 `screen_side` 锁侧位。
- 角色左右互换 → 越轴了，机位移到轴线另一侧；把机位表拉回同一侧，或显式标注越轴并给过渡镜。
- 角色忽大忽小 → 没写比例锚，用场景固定尺寸物做换算后重出。
- **灯态穿帮（行人红灯画成红色行走人形／圆形车灯里塞人形／红灯配绿色数字）** → 状态卡缺失或自造符号；按 [continuity.md](continuity.md#十四可变状态卡灯态时间天气门) 的灯态规范重写一句状态卡并全组复制，同时补"车辆正沿本车道直行通过路口"把通行权说圆。
- **角色一格在左、下一格跑到右侧（左右翻转）** → 缺 `screen_side` 或各格自写方位；按 [continuity.md](continuity.md#九屏幕侧位锁定防一格在左一格跑到右) 把侧位写进每格并全组原句复制；反打必须标 `reverse_shot: true`，且下一格切回原侧位。
- **两个主体的参考方向搞反（狗穿猫的纹、A 的头配 B 的身体）** → 缺 `ref_binding`，槽位没绑主体或一张图兼指两个主体；按 [continuity.md](continuity.md#十双主体参考绑定防两个主体的参考方向搞反) 一槽一主体重绑，Prompt 逐槽写"图片N 仅提供…"。
- **穿模／粘连／多肢** → 负向只写了基础一段；补齐 `anatomy`/`geometry`/`separation` 三段，并在正向写主体分离句与复杂动作的接触点（见 [continuity.md](continuity.md#十一穿模融合与主体分离)）。
- 光位跳变 → 光位句被各格自写，统一回 `anchors.lighting` 同一句。
- **同一空间不像同一空间** → 蓝图/状态卡/场景固定物形态没逐格复制，或参考图链断在中途；按 `ref` 字段回溯断链点，从断点格起重出。
- 编号乱码 → 让模型画了编号，删掉并在拼板阶段叠字。
- 一格塞多步动作 → 拆成相邻两格，各保留一个主要变化。
- 画面被拉变形 → 拼板时未按 cover 裁切，检查脚本的裁切逻辑而不是拉伸参数。
- 格子与叙事错位 → 镜头单按画面美观拆而非按事件拆，回到内容事件重排。
- **交付后无法复现某一格** → 溯源字段没回写；`prompt`/`seed`/`ref`/`qa` 补齐前不算交付完成。

## 七、风格预设表（可选）

风格是**装饰项，不是质量门**：最多问一次，用户不选就按 `realistic` 走，`style_preset` 缺失只报 WARN，不阻塞开图。问一次的话术：

```text
这条板想要哪种风格？（不选就按原装写实做，风格只影响质感，不影响每格衔接）
1) 原装写实（默认）—— 写实电影质感、真实材质、35mm 细颗粒
2) 黑白线稿 —— 纯黑白线描，结构线＋单方向排线，无灰阶无网点无彩色
3) 黑白灰阶素描 —— 铅笔炭笔、纸纹可见、过渡柔化
4) 日式漫画网点 —— 黑白两色＋网点纸做灰阶，爱用速度线
5) 2D 动画赛璐璐 —— 平涂色块、硬边二值阴影、清晰勾线
6) 国漫 3D —— 卡通比例、边缘轮廓光、材质简化
7) 3A 游戏 CG —— 高精度 PBR、环境光遮蔽、体积光
8) 水彩淡彩 —— 透明叠色、湿边晕染、纸纹留白
```

每个预设都必须同时给齐四件套：**质感句**（进 `anchors.style`，逐格原句复制）、**色板**、**阴影／光影方式**、**负向补充**（并入 `anchors.negative_parts`）。只换名字不换句子，等于没换风格。

| id | 风格 | 质感句 | 色板 | 阴影／光影 | 负向补充 |
|---|---|---|---|---|---|
| `realistic` | 原装写实（默认） | 写实电影质感，真实材质与次表面散射，35mm 细胶片颗粒，浅景深，自然光与可控补光 | 冷灰低饱和，高光克制 | 真实投影与环境光遮蔽，明暗过渡连续 | 不做卡通化、不做扁平色块、不加二次元描边 |
| `line_bw` | 黑白线稿 | 纯黑白线描分镜，结构线为主，交界处单方向排线，纸白底，无灰阶渲染 | 只有 #111 与 #FFF | 排线代替阴影，无渐变、无渲染光照 | 不出现任何彩色、渐变、网点纸、渲染阴影、体积光、胶片颗粒 |
| `graphite` | 黑白灰阶素描 | 铅笔与炭笔灰阶，纸纹可见，软铅过渡与局部炭笔加深，最亮最暗两端压缩 | 五档灰阶，无纯黑死区 | 明暗交界线柔化，投影偏散，可擦痕 | 不出现彩色、网点纸、写实照片质感、塑料高光 |
| `manga_tone` | 日式漫画网点 | 黑白两色加网点纸灰阶，清晰勾线，重点格加速度线与集中线 | 纯黑白＋网点密度 | 网点表达明暗，无真实投影与体积光 | 不出现彩色、写实渲染、照片质感、渐变过渡 |
| `cel2d` | 2D 动画赛璐璐 | 平涂色块、硬边二值阴影、清晰外勾线，高饱和有限色板 | 6–8 色有限色板 | 二值阴影，无渐变；高光为单块亮面 | 不出现真实反射、景深虚化、胶片颗粒、写实皮肤纹理 |
| `guoman3d` | 国漫 3D | 风格化卡通比例 3D，边缘轮廓光，色彩分层，材质简化 | 明亮有限色板，偏国风 | 轮廓光＋分层高光，简化环境反射 | 不做真实反射、毛孔皮肤、照片级材质、写实布光 |
| `aaa_cg` | 3A 游戏 CG | 高精度 PBR，金属布料皮肤各自真实反射，环境光遮蔽重，三点布光加体积光 | 冷灰偏青或暗调 | 真实投影＋AO＋体积光，高动态范围 | 不出现卡通化、扁平色块、网点纸、手绘纸纹 |
| `watercolor` | 水彩淡彩 | 透明水彩叠涂，纸纹与湿边晕染，线稿保留在色层下，色块不填满留白 | 淡青灰米白等低饱和 | 湿边与颜料沉淀，无硬边投影 | 不出现写实照片质感、纯黑死区、3D 渲染光泽、数字网点 |

落地规则：

1. `style_preset` 写进镜头单顶层，一条板只允许一个值；缺失按 `realistic` 兜底（WARN），非法值才 FAIL。
2. 标题卡底色与字体气质跟随同一预设（线稿板用白底细线标题卡，写实板用深底白字）。
3. 换风格＝新任务：重开首格、重跑校验、不复用旧参考图链；但同一份镜头单的 `delta`／`in_state`／`out_state` 可以照抄，因为风格与衔接无关。
4. 用户后续说“再出一版黑白线稿的”时，按同一份内容卡只换 `style_preset` 与四件套，重出一条板。
5. 风格永远不参与校验的“通过/不通过”：任何因为“风格没定”而停下开图的动作都不对。
